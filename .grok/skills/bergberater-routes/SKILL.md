# /bergberater-routes — Named lines

## Steps

1. Identify the line from `routes/` (preferred) or `destinations/areas/<slug>.md`.
2. Read `knowledge/GRADES.md` and `knowledge/SAFETY.md`.
3. **Live check** the named route on at least one of: theCrag, bergsteigen.com, Climbers Paradise, a recent trip report.
4. For each route give:
   - Name, UIAA (and French if useful)
   - Pitches / height
   - **Protection label:** plaisir | alpine | via-ferrata
   - Aspect, descent (rappel vs walk-off), gear
   - Approach time
   - Link (not a copied topo)
5. Update the area file if live data disagrees with the seed.

## Do not

- Paste guidebook topos, pitch-by-pitch beta drawings, or paid photo-topos
- Call mixed/runout lines "well protected"
- Invent a grade
