# Grades

Use UIAA for local limestone multi-pitch. French in parentheses when a source uses it.

## Rough conversion (orientation)

| UIAA | French (approx) | What we call it here |
|------|-----------------|----------------------|
| 4 / 4+ | 4c–5a | Easy alpine / first MSL |
| 5− / 5 / 5+ | 5b–5c | Moderate alpine |
| 6− / 6 / 6+ | 6a–6a+ | Moderate sport / plaisir if bolted |
| 7− / 7 / 7+ | 6b–6c | Hard for this project's default profile |
| 8+ | 7a+ | Out of "moderate" |

Obligatory grade (obl.) is what you must actually climb, not the crux you can A0.

## Protection labels (this project)

| Label | Meaning |
|-------|---------|
| **plaisir** | Modern bolts, stands ready to rappel, no mandatory trad. "Well protected." |
| **alpine** | Mixed bolts / pins / gear, route-finding, walk-off or alpine descent. |
| **via-ferrata** | Steel cable. Not a multi-pitch sport answer. |

E-scale (Stadler / local): E1 ≈ plaisir; E2–E3 ≈ alpine with some bolts; E4+ = serious.

## Default profile (assumed until corrected)

- Bolts: solid 5, comfortable 6−, 6+ possible
- Alpine: 4–5 if protection is honest
- "Moderate" in user language ≈ this band, **not** UIAA 7+
