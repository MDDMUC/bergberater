# Weekend protocol

How to build a 48-hour brief from Bad Tölz.

## Order

1. Dates and constraints (aspect, grade, drive, protection).
2. Live weather: DAV Bergbericht + valley forecast for the candidate massifs.
3. Decide **which day is the long day**.
4. Filter `destinations/INDEX.md`.
5. One named route per pick, with protection label.
6. Write `trips/YYYY-MM-DD-<slug>.md`.
7. Chat: default Sat/Sun pair first, then the ranked list.

## Pairing

| Signal | Long day | Short day |
|--------|----------|-----------|
| Sat stable, Sun storms from west | Saturday, can go west (Wetterstein, Ammergau) | Sunday **east** (Kaiser, Kufstein, Chiemgau), morning only |
| Both days stormy afternoon | Two short morning missions, east preferred | Same |
| Heat + high pressure both days | Highest north wall you can drive | Another north / NW, or rest |

## Output must include

- Weather lookup **date**
- Primary + backup per day
- Abort hour
- Assumed vs confirmed grade
- Last lift if relevant
