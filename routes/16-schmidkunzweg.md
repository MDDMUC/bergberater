| Field | Value |
|-------|-------|
| Suitability rank | **14** |
| Massif | Chiemgauer Alpen |
| Drive from Munich | ~1:30–1:45 to Seehaus |
| Aspect | **N / NE** sockel then ridge |
| Grade | **UIAA 3+** |
| Pitches / height | short alpine pitches + walking |
| Protection | alpine / mixed (classic mountain route, not a sport grid) |
| Best day this weekend | Sunday east, short-ish |
| Status | go — easy alpine, not plaisir |

## Why this line

Easy, east of Munich, north-facing start. Good if 5+ still feels like a lot for a first heat-wave day. More mountain route than sport multi-pitch.

## Approach

Seehaus → Hörndlalm / sockel, same as other Hörndl lines, 1.5–2 h.

## Descent

Same way or the Hörndlalm path.

## Gear

- 50 m rope
- Few draws, slings
- Helmet

Sunday backup if you want to be off early. Not the “well protected sport” brief — label is alpine.

## Do not

- Expect bolts every 2 m
- Confuse with Gelbe Wand (7−)
