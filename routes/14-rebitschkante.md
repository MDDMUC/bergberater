# Rebitschkante — Rotspitz Ostwand

| Field | Value |
|-------|-------|
| Suitability rank | **12** |
| Massif | Rofan / Achensee |
| Drive from Munich | 1:30–1:50 + Rofanbahn |
| Aspect | **East** — morning sun |
| Grade | **5b / 4c obl.** (2 pitches: 5b, 4c) |
| Pitches / height | 2 / 70 m |
| Protection | mixed / sanierte classic |
| Best day this weekend | Saturday, very early |
| Status | go — aspect compromise |

## Why this line

High (~2000 m), short, moderate. Not north. Pair with Hosentöter on the north face if you want shade after the east wall cooks.

## Approach

Rofanbahn → west toward Rotspitz, last steep switchbacks, ~45 min.

## Descent

Normal route from the summit back to the entries.

## Gear

- 60 m double
- 10 draws
- Helmet

## This weekend

Only as a short early Saturday. Prefer Hosentöter (north) on the same mountain.

## Do not

- Start this at noon in a heat wave
- Confuse it with Rotspitz Süd
