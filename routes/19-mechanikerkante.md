# Mechanikerkante — Kampenwand Nordgipfel

| Field | Value |
|-------|-------|
| Suitability rank | **16** |
| Massif | Chiemgauer Alpen |
| Drive from Munich | 1:15–1:30 + Bahn or Hintergschwendt |
| Aspect | **North** |
| Grade | **UIAA 5+** (2 pitches) |
| Pitches / height | 2 / ~70 m |
| Protection | alpine — bolts and fixed threads |
| Best day this weekend | Sunday short |
| Status | go |

## Why this line

True north, short, Sunday-east. A bit harder than the Zeller Nordwand (5−) but still under 6.

## Approach

Bahn or Steinlingalm, then left under the Kaisersäle to the north-face entries.

## Descent

Rap toward Kaisersäle. No loose rock onto people.

## Gear

- 60 m rope
- Draws
- Helmet
